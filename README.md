# VaultEconomy (Modern Vault Economy Engine) 💳

**VaultEconomy** is a lightweight, high-performance economy plugin designed for **Paper 1.21.1+** servers.

---

## Commands

- /balance - View your balance
- /pay <player> <amount> - Transfer money to another player
